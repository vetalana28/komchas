# Моды сборки

| Мод | Зачем | Статус |
|---|---|---|
| **Комендантский час** (свой мод, папка `mod/`) | расписание, сирены, Метка, доверие, мысли, диалоги, Тихие | в разработке (v0.1) |
| Cold Sweat | система холода, на которой держится отключённое отопление | сверить версию |
| Simple Voice Chat | голосовой чат для двух игроков; позже голосовые подделки Хора | сверить версию |
| Sound Physics Remastered | звук отражается от стен и глушится дверями; сильно усиливает хоррор | сверить версию |
| Player Animator, Not Enough Animations, Emotecraft | анимации движений героинь | сверить версию |
| Embeddium + Oculus | производительность и поддержка шейдеров | сверить версию |
| FerriteCore, ModernFix, Entity Culling | оптимизация | сверить версию |

Шейдеры (Complementary и подобные) ставятся отдельно, по желанию игрока.
Голос Хора в финале (подделка голосов игроков) нужно писать своим кодом и только с согласия обеих игроков.

## Кандидаты, которые стоит добавить (по образцу Silence in Head)

Названия взяты из чужой сборки, слаги и совместимость версий проверяйте сами на Modrinth или CurseForge (1.20.1 Forge).

| Нужно | Кандидаты |
|---|---|
| Доска дел (сюжет заданиями) | FTB Quests (+ FTB Library, FTB Teams, Architectury) |
| Фоновые звуки и шаги | AmbientSounds, Sounds, Presence Footsteps |
| Эффекты на экране и частицы | EnhancedVisuals, SubtleEffects, Particular |
| Свет | Dynamic Lights, Flashier Flashlights (фонарик) |
| Анимации тела и руки | Fresh Animations (ресурспак), First Person, Not Enough Animations |
| Свои меню и загрузка | FancyMenu, Drippy Loading Screen, Konkrete |
| Свой мир и ресурсы | Paxi (подключение датапаков и ресурспаков из папки config) |
| Анимации существ | GeckoLib (для Подражателей, Старших, Колосса) |
